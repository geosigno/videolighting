Benchmark CSS du glow

Regarde d'abord le rendu de chaque variante dans l'aperçu. Puis Mesurer empile 24 puis 48 glows sur une même boîte, couleurs changeant à chaque frame, et regarde si la page garde son débit d'images. Chaque variante est mesurée 3 fois dans un ordre qui tourne : un palier n'est tenu (✓) que si les 3 tours le tiennent, et les écarts min-max sont affichés. Les variantes « sans masques », « sans coins », « will-change » et « contain » servent à savoir ce qui coûte. Compte une trentaine de secondes. Prérequis : bun run dev (ou dev:lan sur un téléphone).
